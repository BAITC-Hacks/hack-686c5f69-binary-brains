# Сценарий демонстрации каталога

## Реальные данные ekt.kz

Для запуска нужны серверные учётные данные в `.env.local`. Выполните:

```sh
npm run check:alternative-live
```

Команда проверяет карточку KAMELYA MAXI, id `18161`, артикул `150100708_`, и свежие данные кандидата AKASYA MAXI, id `23181`, артикул `150100705_`.

На проверке 23.09.2026 исходный товар имел остаток 0, кандидат — 3. Цифры могут измениться. Алгоритм проверяет совпадение категории, 2×E27, диаметра 400 мм, IP20, способа монтажа, материала корпуса и типа источника света. Запрос трёх детальных карточек при контрольном запуске занял 426 мс; это единичное измерение, не гарантия задержки.

Обязательные отличия в ответе покупателю:

- Световой поток: 1465 → 1152 лм по сведениям каталога.
- Рассеиватель: «Призма» → «Опаловый рассеиватель (белый)».

Пример формулировки: «Исходного светильника сейчас нет. Есть кандидат AKASYA MAXI с теми же 2×E27, диаметром 400 мм и IP20. У него другой рассеиватель и меньший световой поток по каталогу — 1152 вместо 1465 лм. Подойдут ли вам эти отличия?» Остаток в таком сообщении подставляется только из свежей карточки. Для полной совместимости ещё могут потребоваться напряжение, допустимая мощность ламп и размеры крепления; профиль не подтверждает их.

Нельзя говорить, что товары полностью идентичны, что замена уже одобрена или что товар добавлен в корзину.

## Через Python-ассистента

Первый терминал:

```sh
npm run start:catalog
```

Второй терминал:

```sh
python scripts/catalog-client-example.py --live
```

Сервис по умолчанию индексирует 5 страниц, содержащих эту пару. Пример использует заранее выбранный список кандидатов и профиль из `src/lib/alternatives/profiles.ts`; это воспроизводимая репрезентативная проверка, не доказательство поиска по всему каталогу.

## Сертификаты

В просмотренных 100 API-карточках ссылки не обнаружены. `not_provided` означает «ссылка не передана», а не «товар не сертифицирован». `unresolved` означает, что поле есть, но нужна дополнительная информация, например URL вместо числового ID. Такие случаи нужно передавать менеджеру, не придумывая файл.

Публичная [карточка ЩРН-24 на ekt.kz](https://ekt.kz/catalog/shkafy_shchity/shchity_metallicheskie/raspredelitelnye_modulnye_shchrn_shchrv/shchrn_24_395kh310kh120_ekt/) также содержит текст «Сертификат соответствия», но проверенный HTML не содержал прямой ссылки на документ. Это не подтверждает наличие доступного файла в API.

## Если сеть недоступна

Отдельный синтетический сценарий запускается `npm run start:catalog:demo`, клиент — без `--live`. Данные помечены `source=demo`. Никогда не переключайте на них живой запрос молча.
