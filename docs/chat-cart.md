# Интерфейс и корзина (участник 3)

## Локальный запуск

Требуется Node.js 20.9 или новее. Из корня репозитория:

```bash
npm ci
npm run dev
```

Откройте `http://localhost:3000`. Для проверки сборки: `npm run typecheck` и `npm run build`.
Без `.env.local` каталог работает на демонстрационных данных. При наличии доступа к ekt.kz создайте `.env.local` по `.env.example`; не публикуйте логин и пароль.

## Сценарий

1. Задайте вопрос о товаре в чате или загрузите JPEG, Excel, Word либо PDF. Распознавание некоторых форматов пока зависит от блока участника 2.
2. На карточке выберите количество и нажмите «Выбрать». Сервер проверит текущие остатки и выдаст одноразовый токен подтверждения на 10 минут. Корзина на этом шаге не меняется.
3. Нажмите «Да, добавить в корзину» или напишите это в чате. Сервер повторно запрашивает карточку товара, проверяет остаток и кратность `KRATNOST_MIN`, после чего добавляет строку. Повтор одного токена не добавляет товар ещё раз.
4. Откройте `/cart` по ссылке. На мобильном устройстве чат и карточки переходят в одну колонку.

## Контракт корзины

- `GET /api/cart` возвращает `{ items, cartUrl: "/cart", demo: true }` и устанавливает `HttpOnly` cookie сессии.
- `POST /api/cart/prepare` принимает `{ "productId": "demo-515291", "quantity": 1 }` и отвечает `{ confirmationToken, product, quantity, expiresInSeconds }`; запись в корзину отсутствует.
- `POST /api/cart/confirm` принимает `{ "confirmationToken": "..." }` и возвращает актуальную корзину после добавления. Токен привязан к cookie сессии и одноразовому выбору.
- `POST /api/chat` при точной фразе «да, добавь» подтверждает ожидающий товар ассистента через ту же серверную корзину. Сообщения с вопросом про доставку не считаются подтверждением.

Корзина хранится в памяти одного процесса. Она сбросится после перезапуска сервера и не будет общей между несколькими экземплярами. Реальный API корзины ekt.kz не подключён: покупка, резервирование склада и оплата на сайте не выполняются. Для продакшена потребуется постоянное хранилище, авторизация пользователя и интеграция с корзиной платформы ekt.kz.
