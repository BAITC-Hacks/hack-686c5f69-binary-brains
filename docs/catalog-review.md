# Проверка блока каталога — 23.09.2026

Область: API каталога, поиск, нормализация карточек и складов, сертификаты, аналоги, HTTP-интеграция с Python. Чат, загрузка документов и изменение корзины относятся к другим участникам.

## Найдено и исправлено

1. Общий подбор проверял первые 30 позиций в порядке каталога. Подходящий кандидат дальше в выборке мог не попасть в проверку. Теперь перед ограничением количества выполняется ранжирование по сходству названий; пригодность по-прежнему определяется свежими характеристиками и остатком. Регрессионный тест размещает кандидата после 40 нерелевантных товаров.
2. Диапазон серии «номинальный ток 6 А — 250 А» ошибочно воспринимался как характеристика конкретного товара. Диапазоны отделены от одиночного номинала; настоящие противоречия 160 А / 250 А продолжают выявляться.
3. Противоречие «E14 в свойствах / E27 в тексте» не блокировало подбор. Добавлена проверка согласованности цоколя и тест отказа от такого кандидата.

Дополнительно введён общий срок подбора 4 секунды с отменой зависшего API-запроса. Проверка прекращается после набора нужного количества результатов. Частичные результаты явно помечаются. Добавлена статическая проверка TypeScript и lock-файл зависимостей разработки.

## Выполненные проверки

- `npm run typecheck` — успешно.
- `npm test` — 30 успешных тестов.
- `npm run check:alternative-live` — общий подбор по первым 100 товарам без заранее заданного id кандидата. Найден `150100705_` для исходного `150100708_`.
- `python scripts/catalog-client-example.py --live` — общий поиск через HTTP повторно проверен на живом API, без `candidateIds` в запросе.
- Контрольный запуск общего сценария: 1888 мс, включая первоначальную загрузку индекса; разовое измерение, не SLA.
- Свежие остатки во время проверки: исходный товар 0, кандидат 3. Результат явно показывает меньший световой поток (1465 → 1152 лм) и другой рассеиватель; требуется согласование.
- Ошибки авторизации/сети не превращаются в нулевой остаток. Подтверждены свежие запросы деталей, защита от зацикленной пагинации, неполная выборка, отказ от некорректных HTTP-запросов, обработка слишком большого JSON.
- В Git для этого репозитория установлен автор `nurakhmetasima`; `.env.local` и служебные снимки `.local/` исключены из Git.
